====================================================
PROJECT 23 — BOSS BATTLE AI
====================================================

Game Title:
Boss Battle AI

Description:
Boss Battle AI is an action-packed Python and Pygame project where players
battle against a powerful AI-controlled boss enemy. The game includes dynamic
boss attacks, player movement, health systems, explosions, projectiles, visual
effects, and survival gameplay mechanics.

This project was created as part of the book:

"25 AI Game Development Projects for Kids and Teens"

----------------------------------------------------
FEATURES
----------------------------------------------------

- AI-controlled boss enemy
- Dynamic attack patterns
- Health and damage systems
- Animated gameplay effects
- Player movement and shooting
- Boss battle arena
- Sound and visual effects
- Beginner-friendly Python code

----------------------------------------------------
TOOLS AND LIBRARIES
----------------------------------------------------

- Python 3.12
- Pygame

----------------------------------------------------
INSTALLATION
----------------------------------------------------

1. Install Python 3.12
2. Install Pygame using:

py -3.12 -m pip install pygame

----------------------------------------------------
HOW TO RUN THE GAME
----------------------------------------------------

Open the project folder and run:

py -3.12 project23.py

----------------------------------------------------
GAME CONTROLS
----------------------------------------------------

Arrow Keys or WASD  = Move Player
SPACE               = Shoot
ESC                 = Quit Game

----------------------------------------------------
GAME OBJECTIVE
----------------------------------------------------

Survive the boss attacks, avoid projectiles, and reduce the boss health to win
the battle.
